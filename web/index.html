How does live capture work in a browser?

It can't, directly: web pages are sandboxed and cannot open a network card. So live capture uses a small helper that runs on your computer, captures with tcpdump and streams packets to this page. It listens on 127.0.0.1 only and needs a private token.

sudo node web/agent/bavin-agent.js

Prefer files? Record one with sudo tcpdump -i any -w capture.pcap (or Wireshark) and drop it here.

What it understands

    Also decoded: 802.1Q VLAN tags, IPv6 extension headers, mDNS, and TLS record headers (including the SNI hostname in a ClientHello). Everything else is shown as raw payload.

    Live capture

    Browsers cannot read your network card, so live capture uses a tiny helper that runs on your computer. It captures with tcpdump, listens on 127.0.0.1 only, and needs a private token.

    1. Download the agent — one small file, open source; read it before running it with admin rights.
    2. Run it, allowing this site:
    3. Paste the link it prints: 
    sudo node web/agent/bavin-agent.js

    Then open the URL it prints (it ends in #token=…).

    No packets to spare? --replay some.pcap streams a capture file as if it were live, without any privileges. Details in web/README.md.

    Capturing needs administrator rights on the agent, not in the browser. Keeps the newest 100,000 packets.
